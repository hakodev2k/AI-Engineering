# PR Context Analysis Skill

## Purpose
Collect enough repository evidence before generating a pull request summary or review package.

## Process
1. Inspect repository structure.
2. Identify changed files and ownership.
3. Trace affected code paths.
4. Locate related tests.
5. Collect build and test evidence.
6. Separate facts from assumptions.
7. Produce findings with evidence.

## Output
- changed areas
- risk assessment
- missing verification
- unresolved questions

## Stop Conditions
Stop when evidence is insufficient instead of guessing.
