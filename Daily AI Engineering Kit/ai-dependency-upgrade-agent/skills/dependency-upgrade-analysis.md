# Dependency Upgrade Analysis Skill

Purpose: evaluate upgrade impact before editing code.

Process:
1. Identify current and target versions.
2. Read release notes and migration guidance.
3. Locate affected APIs in repository.
4. Find tests covering affected areas.
5. Create risk assessment.
6. Implement smallest safe change.
7. Run validation.

Output:
- affected components
- evidence
- risk
- migration steps
- verification status

Stop when evidence is insufficient or approval is required.
