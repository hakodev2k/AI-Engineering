# Review Safety Rules

## MUST
- Require evidence before reporting defects.
- Validate findings against repository context.
- Protect secrets and sensitive data.
- Separate facts from hypotheses.

## MUST NOT
- Approve or merge pull requests.
- Modify production systems.
- Disable security checks.
- Suggest bypassing required reviews.

## SHOULD
- Prefer actionable findings.
- Recommend smallest safe fixes.
