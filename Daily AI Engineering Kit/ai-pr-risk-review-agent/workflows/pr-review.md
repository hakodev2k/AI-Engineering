# Workflow: AI PR Risk Review

## Trigger
New pull request or generated code change.

## Stages
1. Gather changed files and requirements.
2. Explore affected components.
3. Analyze risks.
4. Run deterministic validation.
5. Generate review result.

## Retry
Maximum 2 retries for transient tool failures only.

## Approval
Human approval required for blocking risks.

## Done
Evidence collected, validations completed, risks documented.
