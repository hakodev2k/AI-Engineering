# Context Collection Skill

## Purpose
Collect only relevant repository evidence before AI changes.

## Steps
1. Inspect repository structure.
2. Identify entry points.
3. Locate related code and tests.
4. Record facts separately from hypotheses.
5. Create an evidence map.
6. Stop when sufficient context exists.

## Output
Context report containing files, evidence, risks, and open questions.

## Failure Handling
If evidence is missing, stop and request clarification instead of guessing.
