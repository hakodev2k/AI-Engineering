# PR Review Workflow

## Trigger
A pull request requires review.

## Stages
1. Gather repository context.
2. Create review plan.
3. Run specialized reviews.
4. Execute deterministic checks.
5. Generate findings.
6. Request human approval for risky changes.

## Retry Policy
Maximum 2 retries for transient tool failures.
Preserve collected evidence.
Escalate after failure.

## Done Criteria
All findings are evidence based and verification status is recorded.
