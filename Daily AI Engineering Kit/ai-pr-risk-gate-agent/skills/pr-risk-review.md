# PR Risk Review Skill

## Purpose
Evaluate pull requests with evidence.

## Steps
1. Inspect changed files.
2. Identify affected modules and contracts.
3. Review tests and coverage.
4. Check security and operational impact.
5. Record findings with evidence.
6. Verify unresolved risks.

## Output
Finding, evidence, severity, recommendation, verification status.

## Stop Conditions
Stop when required context is unavailable or approval is required.
