# Incident Investigation Skill

## Purpose
Perform structured root-cause analysis.

## Process
1. Identify incident timeline.
2. Collect logs, metrics, traces, deployments, and affected components.
3. Separate facts from hypotheses.
4. Map request flow and state changes.
5. Create ranked hypotheses.
6. Validate each hypothesis with evidence.
7. Propose smallest safe remediation.
8. Define verification checks.

## Output
Finding, evidence, confidence, risk, recommendation, verification status.

## Stop Conditions
Stop when evidence is insufficient or approval is required.
