# Incident Investigation Skill

## Purpose
Investigate production failures using evidence-driven reasoning.

## Steps
1. Identify impact and timeline.
2. Collect logs, metrics, traces, deployments, and configuration changes.
3. Map affected components.
4. Separate facts from hypotheses.
5. Validate hypotheses with evidence.
6. Recommend smallest safe remediation.
7. Verify recovery.

## Output
Finding, evidence, confidence, risk, recommendation, verification status.

## Stop Conditions
Stop when evidence is insufficient or approval is required.
