# Dependency Impact Analysis Skill

## Purpose
Analyze dependency changes before editing.

## When to use
Before upgrading packages, frameworks, SDKs, or runtime components.

## Process
1. Identify current version and target version.
2. Locate direct usages in source code.
3. Inspect changelog and migration notes.
4. Find affected APIs, configuration, and tests.
5. Classify risk.
6. Produce upgrade plan.

## Output
Finding, evidence, affected files, risk level, migration steps, verification plan.

## Stop conditions
Stop when migration requirements are unknown or approval is required.
