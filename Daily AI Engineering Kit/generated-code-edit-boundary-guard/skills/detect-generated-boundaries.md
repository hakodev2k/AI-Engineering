# Detect Generated Boundaries

## Purpose
Identify files that are generated, vendored, mirrored, compiled, derived, or otherwise unsafe to edit directly.

## When to use
Run before any AI-assisted edit, refactor, formatting pass, bulk rename, code review fix, or repository-wide transformation.

## Inputs
- Repository root
- Candidate changed paths or planned edit scope
- `config/generated-boundary-policy.json`

## Preconditions
- Repository is readable.
- Current branch and HEAD are known.

## Allowed tools
Read/search files, Git status/diff, deterministic scripts in this package.

## Constraints
- Do not write candidate files during detection.
- Do not infer editability from file extension alone.
- Treat unknown ownership as unresolved, not editable.

## Procedure
1. Inspect repository markers such as `*.g.cs`, `*.generated.*`, `obj/`, `dist/`, `build/`, `vendor/`, lock-generated files, generated OpenAPI/GraphQL clients, ORM artifacts, protobuf outputs, source-generator outputs, compiled assets, and policy-configured patterns.
2. Search file headers for generated markers such as `auto-generated`, `generated by`, `do not edit`, or tool signatures.
3. Inspect nearby build scripts, package scripts, project files, makefiles, CI jobs, generator configs, schemas, templates, IDLs, and source-generator registrations.
4. For each candidate path classify `source`, `generated`, `vendor`, `derived`, or `unknown`.
5. For `generated` or `derived`, identify the source-of-truth path and regeneration command when evidence exists.
6. For `vendor`, identify upstream ownership and update mechanism.
7. Record evidence and confidence in a boundary manifest.
8. Stop if a planned edit targets `generated`, `vendor`, `derived`, or `unknown` without an approved exception.

## Expected output
A manifest compatible with `schemas/generated-boundary-manifest.schema.json`.

## Verification
Run:

`python scripts/validate-generated-boundary.py --manifest <manifest.json> --policy config/generated-boundary-policy.json`

## Failure handling
- Missing source-of-truth: classify as `unknown` and block direct edit.
- Missing generator command: preserve evidence and escalate for human clarification.
- Conflicting evidence: keep highest-risk classification and require review.

## Stop conditions
Stop before editing when any target path is not classified `source` or has an unresolved exception requirement.
