# Skill: Investigate Incident

## Purpose
Perform structured root-cause analysis using evidence.

## Process
1. Identify incident scope and impact.
2. Collect logs, metrics, traces, deployments, and related code.
3. Separate facts from hypotheses.
4. Build candidate causes.
5. Validate each hypothesis with evidence.
6. Produce findings with confidence and unresolved risks.

## Output
- Finding
- Evidence
- Confidence
- Affected component
- Recommended action
- Verification status

## Stop Conditions
Stop when evidence is insufficient or approval is required.
