# Dependency Impact Analysis Skill

## Purpose
Analyze dependency upgrades before implementation.

## Process
1. Identify current dependency version and target version.
2. Locate usage sites, configuration, tests, and deployment references.
3. Review changelog and breaking changes.
4. Classify risks: compile, runtime, security, performance, behavior.
5. Create evidence-based upgrade plan.
6. Validate with build and tests.

## Output
- Dependency
- Current version
- Target version
- Affected components
- Evidence
- Risk
- Verification status

## Stop Conditions
Stop when required documentation is unavailable, tests cannot run, or approval is required.
