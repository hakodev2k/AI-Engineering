# PR Review Skill

## Purpose
Perform structured pull request review.

## Steps
1. Collect changed files and metadata.
2. Identify affected modules.
3. Read related tests and contracts.
4. Classify findings by severity.
5. Validate findings against evidence.
6. Report actionable recommendations.

## Output
Finding, evidence, severity, affected component, recommendation, verification status.

## Stop conditions
Stop when repository context is insufficient or approval is required.
