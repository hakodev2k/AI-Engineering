# Skill: API Consumer Discovery

**Purpose:** turn requests into verified consumer problems and outcomes. **Trigger:** new request, repeated support friction, adoption drop, or roadmap discovery.

## Inputs
Consumer segment, request/ticket/interview evidence, usage data, current workflow, business objective, constraints.

## Procedure
1. Identify consumer and job-to-be-done.
2. Map current task from discovery through successful outcome.
3. Collect qualitative and quantitative evidence; note sample limitations.
4. Separate requested solution from underlying problem.
5. Quantify frequency, severity, affected cohorts, workarounds, and cost of delay.
6. Define desired outcome and candidate success metrics.
7. Record assumptions and unknowns; determine whether discovery is sufficient to prioritize.

## Decisions
Proceed when evidence supports a material problem. Run a reversible experiment when confidence is medium. Stop/escalate when the request depends on unsupported legal/security/business commitments.

## Output
Problem statement, consumer segments, evidence, current journey/friction, desired outcome, assumptions, open questions, metrics, recommendation.

## Quality and verification
At least one evidence source must support each major claim; solution language must not replace problem definition; affected consumer scope is explicit. Failure to obtain critical context stops commitment.
