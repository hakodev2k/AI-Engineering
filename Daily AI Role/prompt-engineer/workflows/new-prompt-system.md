# Workflow: New Prompt System
**Trigger:** new repeatable AI task. **Goal:** release a verified reusable prompt system. **Stages:** intake -> task contract -> context design -> prompt architecture -> output contract -> evaluation design -> candidate -> parallel domain/safety/eval review -> consolidation -> bounded fixes -> verification -> version -> release/handoff. **Dependencies:** evaluation follows frozen candidate; release follows critical-case pass. **Retries:** max 2 prompt revision cycles, then reassess task/model/tool/data design. **Failure path:** block release and escalate unresolved critical findings. **DoD:** checklist complete, evidence stored, rollback target defined.
