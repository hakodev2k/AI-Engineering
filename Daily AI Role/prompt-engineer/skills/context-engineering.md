# Skill: Context Engineering
**Trigger:** behavior depends on external knowledge, files, history, or tool results. **Procedure:** classify context as required/optional/noise; identify freshness and authority; define retrieval scope; preserve provenance; compress only when critical constraints survive; order context by task dependency; define missing/stale/conflicting-context behavior. **Decision:** if source authority is ambiguous, surface conflict. **Output:** context plan and inclusion rules. **Verification:** tests cover omitted, stale, contradictory, and oversized context.
