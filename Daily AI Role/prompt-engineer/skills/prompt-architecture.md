# Skill: Prompt Architecture
**Trigger:** task contract ready. **Inputs:** contract, model/tool constraints, reusable instructions. **Procedure:** partition stable role behavior, task policy, dynamic context, examples, and output contract; remove duplicated/conflicting instructions; order by authority and dependency; encode stop/escalation rules; keep tool assumptions isolated. **Constraints:** do not embed secrets or unverifiable claims. **Output:** candidate prompt architecture plus rationale. **Quality:** concise enough to maintain, explicit enough to test, modular enough to reuse.
