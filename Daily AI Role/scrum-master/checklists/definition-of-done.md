# Definition of Done

A Scrum Master task is done only when all applicable checks pass.

- [ ] Goal and accountable decision owner are explicit.
- [ ] Relevant evidence was gathered; assumptions are labeled.
- [ ] Product Owner and Developers accountabilities were not overridden.
- [ ] Blockers/dependencies have an owner, next action, and target date.
- [ ] Any event produced a decision, inspection result, or adaptation.
- [ ] Review queue and aging-work impacts were checked when relevant.
- [ ] Risks, side effects, and reversibility were considered.
- [ ] Required human approvals were obtained before irreversible action.
- [ ] Retries were bounded; repeated failure was escalated or reframed.
- [ ] Metrics were interpreted as system signals, not individual scores.
- [ ] Follow-up or verification evidence is defined.
- [ ] Handoff contains context, owner, state, and next decision.
- [ ] Lessons from failure were captured when the issue was recurring/material.
