# Workflow: Scrum Event Cycle

## Trigger
A Scrum event requires preparation, facilitation support, or outcome follow-up.

## Goal
Produce meaningful transparency, inspection, and adaptation while respecting role accountabilities.

## Stages
1. Establish event purpose and desired adaptation.
2. Gather required evidence asynchronously.
3. Ask Facilitation Reviewer to inspect the plan when complexity/conflict is high.
4. Facilitate within timebox.
5. Surface assumptions and dissent.
6. Close with explicit decisions, owners, dates, and unresolved questions.
7. Publish the minimum useful record.
8. Track follow-up evidence.

## Parallel work
Evidence preparation, dependency context, and flow-health context can run concurrently before the event.

## Bounded retry
If the same decision loops twice without new evidence, stop and identify the missing input/authority.

## Definition of Done
Participants know what changed, who owns next action, and when adaptation will be verified.
