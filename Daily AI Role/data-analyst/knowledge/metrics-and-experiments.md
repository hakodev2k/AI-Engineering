# Metrics and Experiments

## Metric contract
Record name, business meaning, entity grain, numerator/denominator, eligibility, exclusions, event/source mapping, timezone, freshness expectation, owner, and known caveats.

## Experiments
Before reading outcomes verify assignment unit, randomization integrity, exposure logic, sample ratio mismatch, guardrail health, analysis window, repeated peeking policy, and missingness. Report effect size with uncertainty, not only a p-value.

## Observational analysis
Name confounders, selection mechanisms, instrumentation risks, and temporal alternatives. Use matched/cohort/pre-post methods only with explicit assumptions.

## Dashboard discipline
A dashboard is a monitoring interface, not automatically an explanation. Escalate metric-definition drift or source breakage rather than narrating bad data.
