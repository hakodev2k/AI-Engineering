# Workflow: Benchmark Evaluation
Trigger: choosing among technologies, methods, models, or implementations where performance/quality matters.
Goal: compare options fairly under representative conditions.
Stages: define decision metrics -> baseline -> environment lock -> protocol review -> execute parallel independent cases -> analyze variance -> validate -> synthesize.
Approval: required for production-like data, material compute spend, or risky environments.
Checkpoints: protocol before run; anomaly review before rerun.
Retries: one rerun for transient failure; otherwise revise protocol explicitly.
DoD: reproducible protocol, raw results, normalized comparison, limitations, recommendation boundaries.
