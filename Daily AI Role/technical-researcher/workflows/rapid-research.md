# Workflow: Rapid Research
Trigger: bounded decision with short deadline.
Goal: minimum sufficient evidence quickly.
Inputs: question, deadline, decision owner.
Preconditions: scope can be narrowed.
Stages: frame -> prioritize claims -> parallel source search -> validate top evidence -> synthesize -> challenge -> handoff.
Roles: main researcher, Source Scout, Evidence Reviewer.
Parallel work: independent claim/source tracks.
Checkpoint: after initial evidence, confirm whether recommendation can still change.
Review: independent evidence review for high-impact claims.
Retries: one targeted retrieval cycle after synthesis; transient tool retry max 2.
Failure: expose unverifiable claims and impact.
DoD: decision-ready answer, traceable claims, confidence, residual unknowns, next action.
