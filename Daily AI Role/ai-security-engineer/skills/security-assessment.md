# Security Assessment Skill

## Purpose
Assess security posture and produce actionable findings.

## Trigger
Use when reviewing applications, APIs, infrastructure, or AI systems.

## Procedure
1. Validate scope and inputs.
2. Collect architecture, assets, trust boundaries, and evidence.
3. Separate facts, assumptions, and risks.
4. Identify vulnerabilities and abuse scenarios.
5. Evaluate impact and likelihood.
6. Recommend remediation.
7. Verify fixes.

## Output
Security assessment containing findings, severity, evidence, remediation, and verification status.

## Quality Criteria
Findings must be reproducible, evidence-based, and mapped to affected components.

## Failure Handling
Missing evidence becomes an explicit assumption. High-risk uncertainty is escalated.

## Stop Conditions
Stop when scope is undefined or required access is unavailable.
