# Definition of Done

A work item is done only when all applicable checks pass:

- Scope, critical journey, supported environment and owner are explicit.
- Expected accessibility behavior is testable.
- Automated checks were used where deterministic and useful, but not as sole proof.
- Manual keyboard/focus review completed for interactive changes.
- Semantic/accessibility-tree review completed for structure/state changes.
- Selected assistive-technology review completed for high-risk dynamic interactions.
- Zoom/reflow, contrast, color, motion/media and error/status behavior were checked when applicable.
- All critical/high defects are fixed or have explicit authorized residual-risk approval.
- Fixes were retested against original reproduction steps.
- Adjacent regression coverage was performed.
- Evidence records build/environment, expected vs actual behavior and outcome.
- Failure/root-cause lessons were captured for recurring/systemic issues.
- Handoff names owners, dependencies and follow-ups.
- No secrets or personal/sensitive test data are embedded in artifacts.
