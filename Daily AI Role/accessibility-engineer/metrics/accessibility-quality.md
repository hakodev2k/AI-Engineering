# Accessibility Quality Metrics

Track trends, not vanity counts.

- Critical/high accessibility defects escaped to production.
- Median time to remediate by severity.
- Percentage of critical journeys with current manual accessibility evidence.
- Percentage of shared components covered by deterministic accessibility checks.
- Reopen/regression rate for previously fixed accessibility defects.
- Percentage of release exceptions with explicit owner, expiry/review date and approval.
- Defect concentration by component/pattern to identify systemic debt.
- Evidence completeness rate: environment + steps + expected + actual + severity rationale + retest.

Avoid using raw automated violation count as a standalone success metric; scan volume and page complexity distort it. Pair counts with user impact and critical-journey coverage.
