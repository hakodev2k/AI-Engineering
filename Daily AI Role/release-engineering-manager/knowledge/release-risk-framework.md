# Release Risk Framework

## Purpose
Evaluate release confidence using impact and uncertainty.

## Factors
- User impact
- Business impact
- Security risk
- Reversibility
- Deployment complexity
- Evidence confidence

## Decisions
High risk changes require stronger verification and explicit approval.

## Common mistakes
- Ignoring dependencies.
- Using test success as the only evidence.
- Missing communication plans.

## Example
A critical system change requires validation evidence, recovery planning, and owner approval.
