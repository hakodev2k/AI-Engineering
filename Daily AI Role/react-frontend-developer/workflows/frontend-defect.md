# Workflow: Frontend Defect
Trigger: reported UI defect. Goal: restore correct behavior with regression protection. Stages: reproduce -> classify severity -> preserve evidence -> isolate UI/state/API/browser cause in parallel -> identify root cause -> implement smallest safe fix -> add regression test -> verify neighboring states -> review -> handoff. Do not patch symptoms when root cause remains ambiguous if risk is high. Retry reproduction/tooling at most twice. Escalate API/backend defects with request/response evidence. DoD: original failure no longer reproduces, test/evidence exists and no critical regression is introduced.
