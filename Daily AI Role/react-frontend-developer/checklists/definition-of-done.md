# Definition of Done
- [ ] User goal and acceptance criteria are mapped to observable behavior.
- [ ] Component/state ownership is clear and no unnecessary global state was introduced.
- [ ] Loading, empty, success, validation and failure states are handled where applicable.
- [ ] API contract assumptions are explicit and verified.
- [ ] Keyboard navigation, labels, focus behavior and semantic structure are checked on critical paths.
- [ ] Tests cover high-risk behavior and known regression boundaries.
- [ ] No new console errors, unhandled promises or obvious hydration/render loops are present.
- [ ] Performance impact is reviewed for expensive render/data paths.
- [ ] Security/privacy constraints are preserved.
- [ ] Review comments are resolved or explicitly accepted by the proper owner.
- [ ] Evidence and handoff notes identify residual risks and rollback/recovery path.
- [ ] No required human approval is missing.
