# Skill: Demo Design

**Purpose:** Demonstrate relevant product value credibly against customer decision criteria.

**Inputs:** Discovery, personas, success criteria, product environment.

**Procedure:** Select 2–4 highest-value workflow moments; design narrative; prepare deterministic data; verify permissions; rehearse happy path and one meaningful exception; prepare evidence links; document fallback screenshots/logs only as contingency; state limitations.

**Quality criteria:** Customer-specific, technically accurate, repeatable, within approved environment, and tied to measurable outcome.

**Stop conditions:** Environment instability, unapproved data/access, unsupported claim, or missing prerequisite that changes the conclusion.
