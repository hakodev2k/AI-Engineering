# Project Health Metrics

Use metrics as signals, never as targets to game.
- milestone forecast accuracy;
- schedule variance and consumed float;
- overdue dependency count and age;
- issue mean age by severity;
- risk exposure trend;
- scope-change frequency and cumulative impact;
- decision latency;
- rework caused by unclear ownership/requirements;
- percentage of status claims backed by current evidence;
- handoff defect rate.

Guardrail: a green dashboard is invalid if blocking unknowns, overdue critical decisions or unowned severe issues exist.
