# Skill: Stakeholder Communication

**Purpose:** make project state understandable and decision-ready.

**Trigger:** status cycle, decision needed, escalation, milestone event, material change.

**Steps:** identify audience and decision need; refresh evidence; summarize outcome progress, forecast vs baseline, top risks/issues/dependencies, decisions required and next commitments; tailor detail by stakeholder; state owner/date for every ask; preserve source links.

**Quality:** no unsupported green status, vague "in progress", hidden variance or ownerless action.

**Outputs:** status brief, decision request, escalation brief or handoff note.

**Stop:** if evidence is stale, state that explicitly and request refresh instead of presenting certainty.
