# Production Readiness Review

## Scope
Service/change, owner, launch date, critical user journeys, expected load.

## Reliability Contract
SLIs/SLOs, error-budget policy, dependency objectives.

## Failure Modes
For each: trigger, user impact, detection, mitigation, recovery, owner.

## Capacity
Peak assumptions, bottleneck, quotas, headroom, scale lag, storage growth.

## Dependencies
Timeouts, retries, idempotency, fallback, rate limits, isolation.

## Deployment
Compatibility, migration, staged rollout, rollback/roll-forward, verification.

## Observability
Dashboards, logs, traces, correlation, actionable alerts.

## Data Recovery
Backup, restore evidence, RPO/RTO where applicable.

## Findings
Blocker / required-before-scale / accepted-risk / improvement.

## Verdict
PASS / PASS_WITH_APPROVED_RISK / BLOCK

## Approval
Accepted risks, approver, owner, deadline.
