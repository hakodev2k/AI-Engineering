# Skill: Cost and Capacity Management

**Purpose:** prevent avoidable Azure spend and capacity failures without harming reliability.
**Inputs:** workload utilization, SKU, regions, reservations/savings plans if applicable, quotas, growth forecast, budget.
**Steps:** establish baseline → detect idle/oversized resources → inspect scaling configuration → check quota headroom → model change impact → separate guaranteed savings from assumptions → verify reliability/security constraints → propose reversible optimization → measure after change.
**Output:** prioritized optimization actions with expected impact, confidence, risk, owner, and rollback.
