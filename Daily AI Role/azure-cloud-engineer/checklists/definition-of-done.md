# Definition of Done

- [ ] Intended Azure state is explicitly defined.
- [ ] Subscription, environment, region, and resource ownership are known.
- [ ] Identity and RBAC use least privilege.
- [ ] Network exposure, routing, DNS, and private connectivity are reviewed.
- [ ] Data classification and security/governance requirements are addressed.
- [ ] IaC or documented source of truth exists.
- [ ] Plan/what-if or equivalent pre-change evidence is reviewed.
- [ ] Quotas, capacity, and material cost impact are assessed.
- [ ] Reliability, backup, restore, and DR requirements are addressed.
- [ ] Monitoring, logs, alerts, and ownership are defined.
- [ ] Rollback/recovery strategy exists for production changes.
- [ ] Required human approvals are recorded.
- [ ] Actual post-change resource state is verified.
- [ ] Workload/data-plane behavior is verified.
- [ ] No unresolved critical security, reliability, data-loss, or governance blocker remains.
- [ ] Residual risks and follow-up actions have owners.
- [ ] Handoff is complete when ownership changes.
- [ ] Failure learning is recorded when applicable.
