# Architecture Incident Response
Trigger: production or transformation incident exposes structural architecture failure.
Goal: contain harm and improve enterprise controls without speculative redesign.
Stages: preserve evidence → identify impacted capabilities/systems → parallel boundary/data/integration/technology review → isolate structural cause → immediate guardrail → decision owner review → remediation roadmap → update standards/reference patterns → failure learning.
Stop: security/privacy incident follows specialist incident command first.
Retry: technical validation max 2.
Completion: Failure → Root Cause → Lesson → Process Improvement → Future Prevention, each with owner/evidence.
