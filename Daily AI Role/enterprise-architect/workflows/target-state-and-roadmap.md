# Target State and Roadmap
Trigger: approved transformation outcome.
Goal: define actionable target and transition states.
Stages: outcome/capability framing → constraints → target options → parallel domain reviews → selected target → dependency graph → transition states → roadmap/checkpoints → approvals → handoff.
Parallelism: domain analysis may run concurrently; final target and sequencing serialized.
Human gate: irreversible platform/vendor, regulated-data or material investment choice.
Retry: 2 review/fix cycles maximum.
Failure: target without credible transition path is rejected.
DoD: roadmap has owners, prerequisites, acceptance signals, risk and decommission path.
