# Definition of Done

- [ ] Goal and expected output are explicit.
- [ ] Tool permissions and side-effect level are correct.
- [ ] Deterministic constraints are validated outside free-form model judgment where practical.
- [ ] Loop, retry, delegation, time/cost, and stop bounds are explicit.
- [ ] State/checkpoints support safe resume for long-running work.
- [ ] External effects are traceable and reconciled.
- [ ] Human approvals are recorded where required.
- [ ] Failure-mode review has no unresolved blocker.
- [ ] Acceptance and regression evaluations pass.
- [ ] Verifier checked actual outcome, not only executor claims.
- [ ] Residual limitations and risks are documented.
- [ ] Handoff identifies owner and next action if anything remains.
