# Performance Delivery Health

Track trends rather than vanity counts:

- Regression escape rate: performance regressions reaching production / protected changes.
- Reproduction success rate: investigations with a representative reproducible case.
- Median time to isolate dominant bottleneck.
- Optimization verification rate: changes with reproducible before/after evidence.
- Invalid benchmark rate and top causes.
- Capacity headroom for critical services.
- Performance gate flake rate.
- Percentage of high-impact findings with independent verification.
- Reopened regression rate.
- Prevention completion rate after performance incidents.

Metrics guide process improvement and MUST NOT incentivize hiding failed experiments.
