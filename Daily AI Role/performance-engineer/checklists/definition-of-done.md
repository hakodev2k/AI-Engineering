# Definition of Done

- [ ] Objective and user/business impact are explicit.
- [ ] Target metric and guardrails are defined.
- [ ] Workload is representative or assumptions are labeled.
- [ ] Baseline is recorded.
- [ ] Environment, dataset, versions, warmup, duration, and concurrency are traceable.
- [ ] Raw evidence is preserved.
- [ ] Confounders and invalid runs are documented.
- [ ] Bottleneck or hypothesis has evidence.
- [ ] Optimization/mitigation is measurable and implementable.
- [ ] Before/after comparison uses the same protocol.
- [ ] Tail latency, throughput, errors, and relevant resource signals were checked.
- [ ] Correctness/security/reliability guardrails pass.
- [ ] High-impact result received independent verification.
- [ ] Human approvals are recorded where required.
- [ ] Residual risk and uncertainty are explicit.
- [ ] Failure -> Root Cause -> Lesson -> Process Improvement -> Future Prevention is captured when applicable.
- [ ] Handoff and next owner are clear for unresolved work.
