# Workflow: Standard Release
**Trigger:** planned release. **Goal:** safe traceable promotion. **Stages:** intake -> manifest -> risk -> provenance/dependency/evidence/rollback reviews in parallel -> consolidate -> readiness gate -> human approval when required -> staging checkpoint -> production promotion -> verification -> closeout. **Dependencies:** serialize incompatible service/data changes; parallelize independent reviews. **Retries:** max 2 after corrective change. **Failure:** hold or invoke failed-release workflow. **Definition of Done:** package checklist passes and final status is completed.
