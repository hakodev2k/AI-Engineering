# Definition of Done
- [ ] Exact commit/tag/version recorded.
- [ ] Immutable artifact identifiers/digests recorded.
- [ ] Dependency order validated.
- [ ] Required tests and security evidence attached.
- [ ] Migration and compatibility risks evaluated.
- [ ] Rollback/recovery path validated.
- [ ] Required human approvals recorded.
- [ ] Release notes and support impact prepared.
- [ ] Promotion completed only through approved environments.
- [ ] Post-deploy smoke, health, and business-critical checks passed.
- [ ] Monitoring shows no unresolved release-caused regression.
- [ ] Exceptions have owners and expiry/review dates.
- [ ] Failure/retry history is documented.
- [ ] Handoff and release closeout are complete.
