# Definition of Done

- [ ] Audience and primary task are explicit.
- [ ] Scope, version, prerequisites, assumptions, and exclusions are clear.
- [ ] Material technical claims map to authoritative evidence or an accountable SME.
- [ ] Commands, code, API examples, and expected results are verified or clearly marked unverified.
- [ ] Safety/security/destructive steps have warnings and required approvals.
- [ ] Terminology is consistent with product/source-of-truth language.
- [ ] Navigation and discoverability are addressed.
- [ ] Links and referenced artifacts resolve.
- [ ] Error paths, limitations, rollback/recovery, or troubleshooting are included where relevant.
- [ ] Required reviewers completed review and conflicts are resolved.
- [ ] Publication target and supported versions are correct.
- [ ] Ownership and future update trigger are recorded.
- [ ] No TODO, placeholder, secret, credential, or fabricated behavior remains.
