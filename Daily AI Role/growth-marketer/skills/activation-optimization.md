# Activation Optimization
Purpose: increase the share of qualified new users reaching first meaningful value.
Trigger: onboarding drop-off or weak early value realization.
Inputs: activation definition, journey events, cohorts, user research, friction logs.
Procedure: validate activation event correlates with downstream value; map time-to-value; identify friction by segment; rank interventions; design minimum reversible change; define primary and guardrail metrics; test; inspect retention quality before rollout.
Decisions: prefer removing friction over adding persuasion when both address the same constraint.
Output: activation diagnosis, intervention brief, test/readout.
Quality: activation is behavior-based and tied to later value.
Failure: proxy lacks downstream relationship -> redefine before optimization.
Stop: intervention reaches decision rule and rollout/rollback is documented.
