# Growth Model Knowledge
Use a journey model such as Acquisition -> Activation -> Retention -> Referral -> Revenue only as a diagnostic scaffold, not a universal truth. Define each stage by observable user value. Prefer bottleneck removal over simultaneous optimization everywhere. Separate leading indicators from durable outcomes. Track time-to-value, stage conversion, retained behavior and economic quality by cohort/segment. A growth loop should describe how an output creates future input; distinguish loops from one-time funnels. Optimize system constraints, not isolated percentages.
