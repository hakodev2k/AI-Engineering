## Related-role choices

- **Release:** use Release Manager for business coordination, Release Engineering Manager for system/gate governance, and Release Engineer for hands-on promotion mechanics.
- **Architecture:** use Enterprise Architect across portfolios, either Solution Architect package for solution decisions, and Software Architect for detailed software structure/NFRs.
- **Security:** use Security Engineer for broad security scope and AI Security Engineer when prompts, models, retrieval, agents, tools, or AI-specific abuse paths matter.
- **AI systems:** use Prompt Engineer for instruction/output contracts and Agent Engineer for tool-using loops, state, memory, and delegation.

One primary role remains accountable when specialist roles are composed.
