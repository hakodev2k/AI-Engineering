# Skill: Demo and Workshop Design
**Trigger:** live event, webinar, conference, internal enablement, launch demo.
**Inputs:** audience level, timebox, product version, environment, event constraints.
**Procedure:** define learning outcome; design shortest meaningful scenario; prebuild safe fixtures; script checkpoints; create fallback path; rehearse cold start and degraded-network cases; remove secrets; verify timing; prepare Q&A boundaries.
**Outputs:** runbook, demo repository/assets, fallback plan, audience exercise, verification record.
**Quality:** can recover from predictable failure without misleading the audience.
**Stop:** unstable feature, unapproved claims, or unrehearsed destructive action.
