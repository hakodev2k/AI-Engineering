# Skill: Developer Issue Triage
**Trigger:** public issue, failed sample, Q&A, bug report, migration problem.
**Inputs:** expected/actual behavior, environment, version, logs, reproduction.
**Procedure:** assess severity/security; gather minimum reproduction context; reproduce; classify product bug/docs gap/sample defect/configuration/support question; identify workaround only if safe; route to owner; communicate confirmed status without speculation.
**Outputs:** triage record, reproduction evidence, safe response, owner handoff.
**Quality:** clear next action and no invented root cause.
**Escalation:** suspected vulnerability, data exposure, outage, billing/access impact.
