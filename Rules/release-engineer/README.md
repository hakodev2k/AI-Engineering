# Release Engineer Rules

Mandatory constraints for artifact promotion, release readiness, deployment verification, rollback, and release evidence. Each rule file is self-contained Markdown and can be copied independently.

## Usage

Use for release and deployment work that needs a focused constraint set without copying the complete Release Engineer role. Pair with target change-management, environment, security, and incident policy.
