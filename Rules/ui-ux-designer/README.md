# UI/UX Designer Rules

Operating constraints for AI-assisted UI/UX design work. Each rule file is standalone policy guidance and can be copied independently; this index and sibling rules are optional navigation rather than runtime dependencies.

## Usage

1. Select the smallest rule set that covers the design decision or change.
2. Combine it with repository-specific product, accessibility, privacy, security, and design-system requirements.
3. Turn critical requirements into review criteria, prototypes, usability checks, or automated accessibility tests.
4. Preserve explicit approval boundaries for high-impact, deceptive, irreversible, or privacy-sensitive design changes.
