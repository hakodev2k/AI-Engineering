# Privacy Design Rules
## Purpose
Protect privacy through minimization, transparency, control, and safe defaults.
## Scope
Collection, permissions, consent, sharing, retention, and deletion.
## MUST
- Explain material data collection and sharing at the point of decision.
- Request only data and permissions necessary for an authorized purpose.
- Provide required consent, revocation, correction, export, or deletion controls.
- Escalate sensitive-data flows for privacy and security review.
## MUST NOT
- Use dark patterns to obtain consent.
- Expose sensitive data by default without review.
## SHOULD
- Prefer privacy-preserving defaults and progressive permissions.
## Exceptions
Mandatory processing requires documented basis and communication.
## Verification
Review data maps, permissions, defaults, copy, revocation paths, and approvals.
