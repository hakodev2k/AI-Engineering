# Visual Hierarchy Rules
## Purpose
Communicate priority, grouping, state, and action without ambiguity.
## Scope
Layout, typography, spacing, emphasis, density, icons, and states.
## MUST
- Make primary actions, headings, relationships, and status distinguishable through consistent hierarchy.
- Preserve readability across supported viewports, text scaling, and content lengths.
- Use approved design-system tokens when available.
## MUST NOT
- Let decoration compete with critical content.
- Encode essential meaning through styling alone.
## SHOULD
- Reduce unnecessary visual variants.
## Exceptions
Branded experiences may diverge when usability and accessibility remain validated.
## Verification
Review responsive mockups, content stress cases, token usage, contrast, and hierarchy.
