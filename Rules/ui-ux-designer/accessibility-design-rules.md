# Accessibility Design Rules
## Purpose
Ensure experiences work for diverse abilities and assistive technologies.
## Scope
Visual, interaction, content, motion, input, and responsive design.
## MUST
- Design to the required accessibility standard.
- Provide non-color cues, visible focus, accessible names, reading order, and keyboard behavior where applicable.
- Validate contrast, zoom/reflow, target sizing, and motion alternatives.
## MUST NOT
- Remove accessibility behavior for visual fidelity.
- Make critical content available only by hover, color, audio, or animation.
## SHOULD
- Prefer native semantic controls.
## Exceptions
Platform limitations require documented impact, mitigation, and approval.
## Verification
Use keyboard, screen-reader, contrast, zoom, and manual accessibility review.
