# Accessibility Engineer Rules

Mandatory constraints for inclusive, usable interfaces. Each rule file is self-contained Markdown and can be copied without this index.

## Usage

Select the rules that apply to the affected user journey, platform, and accessibility target. Pair them with repository policy, product acceptance criteria, and deterministic checks; do not treat an automated scan as proof of accessibility.
