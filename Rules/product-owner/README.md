# Product Owner Rules

Mandatory constraints for backlog readiness, acceptance, sequencing, and outcome clarity. Each rule file is self-contained Markdown and can be copied without this index.

## Usage

Use these rules for product backlog items and change decisions. They complement, rather than replace, organization-level product strategy, legal, security, delivery, and release approvals.
