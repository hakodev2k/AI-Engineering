# Accuracy Validation Rules
## Purpose
Ensure values represent the intended real-world facts.
## Scope
Reference comparisons, reconciliations, calculations, and sampled validation.
## MUST
- Accuracy claims MUST identify an authoritative reference or defensible validation method.
- Derived values MUST be reconciled against source inputs for critical transformations.
- Sampling methods MUST be representative enough for the stated conclusion.
## MUST NOT
- MUST NOT equate format validity with factual accuracy.
- MUST NOT declare accuracy from agent confidence or visual inspection alone when deterministic evidence exists.
## SHOULD
- Independent reconciliation SHOULD be used for financially or operationally critical measures.
## Exceptions
Where no ground truth exists, document proxy metrics, uncertainty, and limitations.
## Verification
Review reconciliations, source comparisons, sampled evidence, formulas, and error rates.
