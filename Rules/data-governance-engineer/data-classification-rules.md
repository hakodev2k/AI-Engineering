# Data Classification Rules
## Purpose
Apply protection proportional to data sensitivity and business impact.
## Scope
Structured, semi-structured, and unstructured governed data.
## MUST
- Data MUST be classified using the organization's approved classification scheme before broad distribution.
- Classification MUST consider confidentiality, integrity, regulatory, contractual, and operational impact.
- Controls MUST follow the highest applicable classification when mixed data is combined.
## MUST NOT
- Sensitive data MUST NOT be downgraded merely to simplify access or tooling.
- Unknown classification MUST NOT be assumed public.
## SHOULD
- Classification SHOULD be automated where reliable signals exist and reviewed at material lifecycle changes.
## Exceptions
A classification exception requires documented evidence, risk acceptance, scope, expiry, and approval.
## Verification
Review catalog labels, automated discovery results, control mappings, and samples of newly created assets.
