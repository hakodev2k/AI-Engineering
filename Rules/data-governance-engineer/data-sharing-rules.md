# Data Sharing Rules
## Purpose
Control internal, external, and cross-domain data distribution.
## Scope
Exports, data products, clean rooms, feeds, APIs, file transfers, and third-party sharing.
## MUST
- Sharing MUST have documented purpose, recipient, classification, permitted use, and applicable controls.
- Sensitive sharing MUST enforce minimization and appropriate transfer/storage protection.
- External sharing MUST define retention, onward-sharing, breach, and termination obligations where applicable.
## MUST NOT
- Data MUST NOT be shared merely because a recipient has technical access.
- Restricted data MUST NOT move to unapproved destinations or jurisdictions.
## SHOULD
- Reusable governed interfaces SHOULD replace recurring manual exports.
## Exceptions
Urgent sharing requires accountable approval, bounded scope, secure transfer, expiry, and retrospective review.
## Verification
Inspect sharing registers, approvals, contracts, transfer controls, recipient access, and termination evidence.
