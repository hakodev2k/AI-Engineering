# Program Closure and Benefits Rules

## Purpose
Close programs with explicit ownership, verified outcomes, and durable follow-through.

## Scope
Program completion, transition to steady state, residual work, benefit realization, and lessons learned.

## MUST
- Program closure MUST verify committed outcomes against defined success criteria.
- Residual work, risks, and obligations MUST have named owners before closure.
- Ongoing metrics and benefit tracking MUST transfer to an accountable owner where relevant.
- Significant lessons and recurring failure patterns MUST be captured for future programs.

## MUST NOT
- MUST NOT declare completion solely because planned tasks are finished.
- MUST NOT leave unresolved obligations without an accountable receiving owner.

## SHOULD
- Programs SHOULD compare realized outcomes with original assumptions and forecasts.
- Closure SHOULD remove obsolete governance and reporting overhead.

## Exceptions
Exceptions require rationale, residual obligations, owner, review date, and accountable approval.

## Verification
Review success metrics, closure records, residual action ownership, handoff evidence, and benefit-tracking assignments.
