# Execution Status Rules

## Purpose
Provide accurate, decision-useful visibility into program execution.

## Scope
Program health, progress, blockers, forecasts, metrics, and executive reporting.

## MUST
- Status MUST reflect current evidence, not desired outcomes.
- Health indicators MUST use explicit criteria and remain consistent over time.
- Material blockers MUST include owner, next action, and target resolution point.
- Forecast changes MUST be communicated when evidence materially changes.

## MUST NOT
- MUST NOT manipulate status categories to avoid escalation.
- MUST NOT report percentage complete without a defined basis.

## SHOULD
- Reporting SHOULD emphasize outcomes, variance, risk, and decisions needed.
- Metrics SHOULD be few enough to remain actionable.

## Exceptions
Exceptions require documented reporting limitations and an alternate evidence source.

## Verification
Review status history, metric definitions, blocker records, and consistency between reported health and underlying evidence.
