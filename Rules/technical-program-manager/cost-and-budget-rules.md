# Cost and Budget Rules

## Purpose
Keep technical program decisions aligned with explicit cost constraints and economic trade-offs.

## Scope
Program budget, cloud or infrastructure spend, vendor cost, staffing assumptions, and cost-impacting scope decisions.

## MUST
- Material cost assumptions MUST have a source, owner, and review point.
- Scope or architecture changes with meaningful cost impact MUST include updated estimates.
- Budget variance MUST be communicated when it can affect committed outcomes.
- Cost decisions MUST consider lifecycle and operating cost where relevant.

## MUST NOT
- MUST NOT present unvalidated estimates as committed financial forecasts.
- MUST NOT optimize only for initial delivery cost when operating cost is material.

## SHOULD
- Programs SHOULD compare cost against expected value and risk reduction.
- Significant recurring costs SHOULD have monitoring or ownership after launch.

## Exceptions
Exceptions require rationale, financial impact, owner, and approval appropriate to the variance.

## Verification
Review budget assumptions, estimate sources, variance reports, change impacts, and post-launch cost ownership.
