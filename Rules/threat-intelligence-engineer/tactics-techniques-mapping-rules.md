# Tactics and Techniques Mapping
## Purpose
Map adversary behavior to defensible behavioral models.
## Scope
Technique classification and defensive mapping.
## MUST
- Map techniques only when source evidence supports the required behavior.
- Record evidence and mapping granularity for each material technique.
- Revisit mappings when framework definitions or evidence change.
## MUST NOT
- Infer techniques from actor reputation alone.
- Inflate coverage by mapping unsupported parent or child techniques.
## SHOULD
- Map observed procedures to detection and control opportunities.
## Exceptions
Hypothesized mappings must be labeled as hypotheses and excluded from confirmed coverage metrics.
## Verification
Peer-review sampled mappings against source evidence and current framework definitions.
