# Observability Engineer Rules

Mandatory constraints for telemetry, service-level objectives, dashboards, and alerting. Each rule file is self-contained Markdown and can be copied independently.

## Usage

Apply these rules to the smallest affected service, workflow, or user journey. Pair them with target retention, privacy, cost, incident, and paging policy; telemetry configuration must not create an uncontrolled data sink.
