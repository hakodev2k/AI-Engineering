# Search Intent Rules
## Purpose
Ensure SEO work satisfies the real task behind a query rather than optimizing strings in isolation.
## Scope
Keyword research, content planning, landing pages, and SERP analysis.
## MUST
- Classify material query groups by user intent and expected result type before selecting a target page.
- Validate intent against current SERP composition and first-party business goals.
- Reassess intent when rankings or SERP composition materially change.
## MUST NOT
- Force informational and transactional intents onto one page when evidence shows different needs.
- Treat keyword volume as proof of business relevance.
## SHOULD
- Cluster semantically related queries that can be satisfied by one coherent page.
## Exceptions
A mixed-intent page is acceptable when SERP evidence consistently rewards mixed formats and the page can satisfy each intent without dilution.
## Verification
Review target-query SERPs, page purpose, conversion path, and query-to-page mapping.
