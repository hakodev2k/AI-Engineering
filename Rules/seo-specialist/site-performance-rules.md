# Site Performance Rules
## Purpose
Protect user experience and search performance through evidence-based web performance work.
## Scope
Core Web Vitals, loading, responsiveness, rendering, and SEO performance recommendations.
## MUST
- Base performance priorities on field data where sufficient representative data exists, supplemented by controlled diagnostics.
- Measure before and after material optimization work using comparable conditions.
- Evaluate performance changes against user experience and functional correctness.
## MUST NOT
- Claim ranking or conversion improvement from a performance change without supporting evidence.
- Remove essential functionality or accessibility solely to improve a synthetic score.
## SHOULD
- Prioritize high-traffic templates and bottlenecks affecting many users.
## Exceptions
Lab data may guide early work when field data is unavailable, but uncertainty must be stated.
## Verification
Field metrics, repeatable lab tests, release comparisons, and regression monitoring.
