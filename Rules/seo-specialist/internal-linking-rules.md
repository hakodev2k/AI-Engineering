# Internal Linking Rules
## Purpose
Create understandable discovery paths and meaningful contextual relationships between pages.
## Scope
Navigation, contextual links, breadcrumbs, hubs, and orphan detection.
## MUST
- Ensure important indexable pages have discoverable internal links from relevant crawlable pages.
- Use anchor text that describes destination context accurately.
- Review internal-link changes for user navigation and crawl impact.
## MUST NOT
- Create hidden, deceptive, or mass irrelevant links for ranking manipulation.
- Depend on search forms alone for discovery of critical content.
## SHOULD
- Allocate prominent links according to user importance and information architecture, not arbitrary SEO quotas.
## Exceptions
Low-discovery utility pages may intentionally receive limited links when their search importance is low.
## Verification
Crawl-depth reports, orphan-page reports, rendered navigation checks, and sampled anchor/destination review.
