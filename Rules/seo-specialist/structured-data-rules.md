# Structured Data Rules
## Purpose
Represent eligible page entities accurately for machine understanding and search features.
## Scope
Schema markup, rich-result eligibility, and structured-data deployment.
## MUST
- Mark up only content or entities that the page genuinely represents and users can substantively access where required.
- Validate syntax and required/recommended properties before release.
- Keep structured data consistent with visible content and current search-engine eligibility requirements.
## MUST NOT
- Fabricate reviews, ratings, authorship, prices, availability, or other structured facts.
- Add irrelevant schema solely to pursue rich-result visibility.
## SHOULD
- Generate markup from authoritative application data when feasible to reduce drift.
## Exceptions
Optional properties may be omitted when reliable source data does not exist.
## Verification
Schema validation, rich-result testing, rendered markup inspection, and search enhancement reports.
