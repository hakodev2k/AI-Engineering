# Definition of Done

A work item MUST NOT be marked done unless applicable checks pass:

- [ ] Objective, scope, time window, owner, and deadline are explicit.
- [ ] Billing/usage evidence source and freshness are recorded.
- [ ] Baseline cost is reproducible.
- [ ] Allocation is attributable or unattributed spend is explicitly quantified.
- [ ] Assumptions and exclusions are visible.
- [ ] Financial impact includes formula, period, and confidence.
- [ ] Reliability, performance, security, compliance, and delivery risks are reviewed.
- [ ] Recommendation includes at least one alternative when trade-offs are material.
- [ ] Required human approvals are recorded.
- [ ] Implementation owner and verification window are defined.
- [ ] Estimated, approved, implemented, and realized savings are not conflated.
- [ ] Rollback/exit plan exists for risky changes.
- [ ] Exceptions have owner, reason, expiry, and review date.
- [ ] Final evidence and handoff are stored.
