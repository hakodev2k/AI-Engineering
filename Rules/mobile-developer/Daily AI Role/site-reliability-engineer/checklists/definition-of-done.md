# Definition of Done

A meaningful SRE task is complete only when applicable checks pass:

- [ ] Goal and user impact are explicit.
- [ ] Service/environment/owner are identified.
- [ ] Assumptions and evidence sources are documented.
- [ ] SLI/SLO implications are addressed.
- [ ] Dependencies and blast radius are understood.
- [ ] Production actions are reversible or explicitly approved.
- [ ] Retry/timeout/stop conditions are bounded.
- [ ] Security, data-loss, and secret exposure risks are checked.
- [ ] Capacity/saturation impact is considered where relevant.
- [ ] Observability supports the required operational decision.
- [ ] Verification uses independent observable evidence.
- [ ] Critical user journey is checked after recovery/change.
- [ ] Known residual risk has owner and deadline.
- [ ] Handoff contains enough context for another operator.
- [ ] Follow-up work is outcome-oriented and measurable.
- [ ] No required approval is implicit.
