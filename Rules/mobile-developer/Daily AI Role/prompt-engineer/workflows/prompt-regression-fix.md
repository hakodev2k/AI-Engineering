# Workflow: Prompt Regression Fix
**Trigger:** production or evaluation regression. **Stages:** triage severity -> reproduce -> freeze evidence -> compare prompt/model/context/tool changes -> minimize failure -> classify root cause -> add regression test -> implement smallest fix -> run affected + critical suites -> review -> version -> rollout. Parallelize environment/change-history inspection with failure minimization. Max 2 failed fixes before escalating architecture/model/tool dependency. DoD: failing case passes, no critical regression, root cause and prevention recorded.
