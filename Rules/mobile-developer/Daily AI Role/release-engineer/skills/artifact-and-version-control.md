# Skill: Artifact and version control
**Trigger:** any candidate release or promotion. **Inputs:** source ref, version policy, build result, artifact metadata. **Preconditions:** build source identified. **Procedure:** validate version uniqueness; map source ref to build; capture immutable artifact digest; verify provenance/attestation if available; separate config from artifact; confirm prior environment used same digest. **Decisions:** reject ambiguous or mutable artifact references for production. **Output:** provenance record and version decision. **Quality:** another operator can identify exactly what is being deployed. **Failure:** quarantine candidate and rebuild once from known source if provenance is untrustworthy. **Stop:** conflicting source/artifact identities.
