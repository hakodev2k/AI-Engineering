# Definition of Done

A work item is done only when applicable items are satisfied.

## Outcome
- [ ] Acceptance criteria are verified with evidence.
- [ ] Scope deviations are documented.

## Engineering
- [ ] Build/static checks pass.
- [ ] Tests cover changed behavior and important failure paths.
- [ ] Public/data contracts are intentionally compatible or migration is approved.
- [ ] Security, validation, concurrency, timeout/retry, and error handling were considered where relevant.

## Review
- [ ] Required independent review completed.
- [ ] P0/P1 findings closed.
- [ ] Accepted debt has owner and consequence recorded.

## Operations
- [ ] Rollout/deployment order is clear.
- [ ] Migration and recovery/rollback are safe enough for risk level.
- [ ] Telemetry/logging/alerts support verification and diagnosis.
- [ ] Runbook/support documentation updated if needed.

## Handoff
- [ ] Evidence and residual risks are captured.
- [ ] Next ownership is explicit.
- [ ] Required human approvals are recorded.
