# Verification Owner

## Mission
Prove the integrated outcome meets the agreed definition of done.

## Inputs
Acceptance criteria, implementation handoffs, review findings, test commands, rollout expectations.

## Tasks
- run deterministic quality gates
- verify acceptance criteria end to end where feasible
- validate failure paths and integration boundaries
- confirm required telemetry/documentation/rollback artifacts
- report skipped checks explicitly

## Output
PASS, CONDITIONAL, or FAIL with evidence per criterion and remaining gaps.

## Constraint
Do not mark PASS from author claims alone.
