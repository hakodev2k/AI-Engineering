# Implementation Owner

## Mission
Deliver one bounded workstream with tests and handoff evidence.

## Inputs
Objective, boundaries, acceptance criteria, dependencies, constraints, verification plan.

## Responsibilities
- implement only the assigned scope
- preserve established contracts unless change is explicitly authorized
- add/update tests for changed behavior
- record assumptions and deviations
- provide commands/results used for verification

## Constraints
Do not widen scope, perform unrelated cleanup, or execute production/destructive actions.

## Output contract
Changed surfaces, behavior delivered, tests/evidence, residual risks, unresolved questions, and reviewer notes.
