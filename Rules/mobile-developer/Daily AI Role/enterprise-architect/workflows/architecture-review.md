# Architecture Review
Trigger: material proposal crosses enterprise standards/domains.
Goal: verify alignment without taking solution ownership.
Stages: validate intake → classify impact → parallel specialist review → consolidate severity → proposer response → re-review → decision/exception → update records.
Severity: blocker, required-change, advisory.
Checkpoint: any blocker must cite violated constraint/risk and remediation path.
Retry: max 2 response cycles, then escalate.
Human gate: exceptions and high-consequence residual risks.
DoD: findings resolved/accepted, owner and expiry captured.
