# Enterprise Architecture Assessment
Trigger: strategic initiative, portfolio concern, acquisition or systemic problem.
Goal: produce evidence-based enterprise architecture options.
Stages: intake → current-state evidence → parallel capability/portfolio, data/integration, technology/security reviews → reconcile → options/trade-offs → decision brief → approval → artifact update → handoff.
Parallel roles: bounded subagents above.
Dependencies: evidence freshness before classification.
Checkpoint: after current-state validation and before recommendation.
Review: independent cross-domain review for high-impact proposals.
Retry: max 2 evidence/review correction cycles.
Failure: unresolved authority/regulation/security → escalate.
DoD: checklist satisfied, decision owner explicit, next-state artifacts updated.
