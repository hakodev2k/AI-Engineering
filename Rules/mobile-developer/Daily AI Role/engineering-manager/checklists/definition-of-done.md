# Definition of Done

A management deliverable MUST have:
- [ ] clear objective and accountable owner
- [ ] evidence and assumptions separated
- [ ] affected stakeholders identified
- [ ] dependencies and blockers recorded
- [ ] capacity or people impact assessed when relevant
- [ ] delivery, quality, reliability, security, and people risks considered
- [ ] options/trade-offs documented for material decisions
- [ ] approval requirements resolved
- [ ] decision and rationale recorded
- [ ] next checkpoint or follow-up date defined
- [ ] measurable success or completion condition
- [ ] handoff complete where ownership changes
- [ ] failure learning captured when this is corrective work
- [ ] no unresolved high-severity risk hidden behind a green status
