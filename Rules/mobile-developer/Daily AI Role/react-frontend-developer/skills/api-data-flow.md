# Skill: API Data Flow
Purpose: integrate remote data predictably. Trigger: read/write API dependency. Inputs: contract, auth rules, cache semantics, UI states. Preconditions: endpoint/contract evidence available. Steps: map transport model to UI/domain model; define query/mutation lifecycle; identify cache/update strategy; handle cancellation/race; model loading/empty/error/retry; protect sensitive fields; test contract edge cases. Decisions: refetch vs optimistic update vs cache patch. Constraints: never invent undocumented fields/status behavior. Output: integration design and evidence. Quality: no hidden stale-state or race assumptions. Verification: exercise success, validation, server error and repeated interaction. Failure: stop on contract ambiguity that can corrupt user-visible state. Stop: all transitions deterministic or explicitly bounded.
