# Workflow: Performance Regression
Trigger: material client performance degradation. Goal: restore agreed user-perceived performance safely. Stages: define scenario/metric -> collect baseline -> parallel network/render/bundle/main-thread analysis -> rank hypotheses -> test dominant hypothesis -> implement -> remeasure -> correctness/a11y regression check -> release evidence. Maximum two speculative implementation attempts before deeper diagnosis/escalation. Human approval required for major UX degradation, browser support reduction or cache/privacy policy changes. DoD: measurable recovery or clear external bottleneck ownership with evidence.
