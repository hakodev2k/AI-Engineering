# Workflow: Feature Delivery
Trigger: approved frontend feature. Goal: ship correct, accessible behavior. Inputs: story/design/API contract. Preconditions: critical context known. Stages: intake -> map user states -> parallel component/API/a11y/test analysis -> implementation -> targeted verification -> independent review -> broader tests/build -> handoff/release. Roles: primary React Frontend Developer integrates; subagents review. Dependencies: shared components and API contracts are source-of-truth. Checkpoints: after plan, after first working behavior, before review, before release. Retry: max two transient tool/build retries. Failure: stop on contract/security/a11y blocker. Human approval: breaking contracts, sensitive data, safeguard bypass. DoD: checklist complete with evidence.
