# Definition of Done

A platform deliverable is complete only when applicable items are true:

- User/team and target developer task are explicit.
- Current pain and expected outcome have evidence.
- Platform contract, ownership boundary, inputs, outputs, and failure behavior are documented.
- Security, reliability, cost, operability, and compatibility risks are reviewed.
- Self-service path is usable without undocumented platform-team intervention.
- Validation covers happy path, failure path, permissions, rollback, and idempotency where applicable.
- Breaking changes have versioning, migration, deprecation window, and rollback strategy.
- Required human approvals are recorded.
- Observability and support ownership exist.
- Documentation and examples reflect shipped behavior.
- Adoption/success metric and review point are defined.
- Bounded retries and escalation rules exist for automation.
- No secrets, placeholder-only behavior, destructive default, or hidden manual prerequisite remains.
- Handoff names owner, open risks, next review, and evidence.
