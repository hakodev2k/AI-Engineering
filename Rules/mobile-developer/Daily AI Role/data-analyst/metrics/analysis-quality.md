# Analysis Quality Metrics

Track trends, not vanity targets:
- decision-ready-on-time rate
- rework caused by metric/source mistakes
- % material analyses with reproducible query/source reference
- % surprising findings independently verified
- canonical metric discrepancy count
- stale-data incidents detected before publication
- stakeholder clarification cycles per request
- unresolved caveat age
- recommendation follow-up completion
- analysis incidents by root-cause class

Never optimize speed by skipping source validation or uncertainty disclosure.
