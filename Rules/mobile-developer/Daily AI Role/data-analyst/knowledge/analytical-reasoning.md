# Analytical Reasoning

- Start from the decision, not from available charts.
- Define the unit of analysis before computing metrics.
- A ratio requires explicit numerator, denominator, eligibility, and time semantics.
- A trend can be composition change, instrumentation change, seasonality, late-arriving data, or real behavior change.
- Segment after validating the aggregate; compare segment mix and within-segment movement.
- Prefer pre-specified hypotheses, but allow exploratory findings to generate—not confirm—new hypotheses.
- Distinguish statistical significance, practical significance, and decision significance.
- A surprising result deserves independent reproduction, reconciliation, or alternate-source validation.
- Correlation is not causation. State the identification strategy before causal language.
- Recommendations should explain expected benefit, uncertainty, downside, reversibility, and next evidence checkpoint.
