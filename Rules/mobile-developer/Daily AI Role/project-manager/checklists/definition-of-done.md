# Definition of Done

A project-management work item is done only when:
- objective, scope, owner and decision authority are explicit;
- schedule impact and dependencies are understood;
- risks, issues, assumptions and decisions are current;
- required approvals are recorded;
- acceptance evidence exists;
- stakeholder communication is complete;
- open follow-up work has owners and dates;
- handoff is explicit;
- no blocking unknown is hidden;
- lessons from material failures are captured.
