# Skill: API Adoption Analysis

**Purpose:** determine whether consumers discover, integrate, complete tasks, retain usage, and derive value.

## Procedure
1. Define adoption funnel and consumer cohorts.
2. Validate instrumentation and denominator definitions.
3. Measure discovery, authentication, first success, real-task completion, retained usage, feature expansion, error/support friction, and economics.
4. Compare cohorts/time periods; investigate confounders.
5. Combine quantitative signals with consumer feedback.
6. Identify highest-friction stage and propose reversible interventions.
7. Define experiment metric, guardrails, duration, and stop condition.

## Output
Adoption diagnosis, evidence, prioritized friction, experiment/recommendation, expected outcome, risks.

Do not equate raw request volume with value.
