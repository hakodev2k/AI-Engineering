# Skill: API Portfolio Prioritization

**Purpose:** rank multiple competing API tasks under constrained capacity.

For each item capture goal, output, consumer/business impact, production/security severity, deadline, dependencies, cost of delay, effort, reversibility, confidence, approval burden, and blocker status.

## Ordering
1. Critical production/security consumer impact.
2. Imminent irreversible/breaking decisions.
3. Dependencies blocking multiple teams/consumers.
4. Committed launch/deprecation milestones.
5. High-value validated adoption or revenue opportunity.
6. Quality/debt improvements with measurable future risk reduction.

Tie-break using impact + cost of delay + dependency centrality + risk, then reversibility, effort, confidence, and approval burden. Never blindly prioritize smallest effort or loudest stakeholder.

## Output
Prioritized queue with rationale, owners, dependencies, next checkpoint, and explicit not-now items.

## Review
Re-evaluate when production severity, evidence, deadline, dependency, or approval status materially changes.
