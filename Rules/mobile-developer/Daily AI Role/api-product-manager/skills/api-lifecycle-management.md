# Skill: API Lifecycle Management

**Purpose:** manage discovery → proposed → beta → active → deprecated → retired states.

For every transition define entry evidence, owner, consumer scope, support/documentation level, compatibility promise, success/failure criteria, communication, and exit criteria.

For deprecation: inventory consumers, define replacement, migration guide, notice channels, support path, dates, exceptions, progress metric, and retirement approval. Track migration by consumer rather than announcement alone.

For retirement: require evidence that consumers migrated or have an approved disposition, dependent systems are ready, monitoring/support are updated, and accountable humans approve irreversible action.

## Output
Lifecycle decision, consumer impact, dates, owners, migration progress, risks, approvals, next checkpoint.
