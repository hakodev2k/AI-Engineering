# Definition of Done

A major API product task is done only when all applicable conditions are true:
- Original objective and target consumer are explicit.
- Required inputs were processed and missing context is resolved or documented.
- Deliverable exists in the expected contract/template.
- Consumer value and success metric are measurable.
- Contract scope and lifecycle/version state are explicit.
- Compatibility impact is reviewed; breaking changes have approved migration/deprecation path.
- Security/privacy/compliance review is complete where relevant.
- Reliability/operability expectations and evidence are sufficient.
- Documentation, examples, support ownership, and communication are ready.
- Dependencies, risks, assumptions, owners, dates, and decision authority are recorded.
- Required human approvals are received.
- Verification evidence exists; no blocking issue remains.
- Handoff allows another person to continue without hidden context.
