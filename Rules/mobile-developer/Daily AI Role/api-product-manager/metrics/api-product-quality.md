# API Product Quality Metrics

Use metrics as evidence, not targets in isolation.

## Consumer value
- task completion rate
- median/p95 time to successful integration
- time to first successful production task
- consumer retention and feature adoption

## Contract trust
- breaking changes without approved migration: target 0
- undocumented behavior incidents
- deprecation migration completion
- contract/documentation defect rate

## Operability
- availability/error/latency against agreed objectives
- support tickets per active consumer
- mean time to consumer recovery for API incidents

## Economics
- infrastructure/support cost per successful consumer task
- quota utilization and abuse rate
- paid conversion/revenue metrics where applicable

Review trends by consumer cohort and lifecycle stage.
