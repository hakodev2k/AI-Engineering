# Workflow: Research Update
Trigger: material new evidence, changed context, stale source, or reassessment.
Goal: update conclusions without repeating unaffected work.
Stages: identify changed assumptions -> diff old/new evidence -> revalidate affected claims -> rerun only necessary experiments -> update synthesis -> record decision delta.
Parallel work: changed source tracks may run concurrently.
Checkpoint: confirm which prior claims remain valid.
Retries: bounded as in original workflow.
DoD: explicit what changed, why, confidence delta, affected decisions, new next action.
