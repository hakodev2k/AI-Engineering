# Skill: Technical RFP/RFI Response

**Purpose:** Produce accurate, consistent, reviewable technical answers.

**Inputs:** Questionnaire, approved answer library, current product/security sources, deadline.

**Procedure:** Classify questions by product, architecture, security/privacy, operations/support, legal/commercial; reuse only source-current approved answers; mark unknowns; route authority-bound questions; perform consistency review across answers; attach evidence where allowed; preserve deviations from standard answer.

**Parallelism:** Product, architecture, and security sections may be researched concurrently after shared terminology is fixed. Consolidate before delivery.

**Output:** Answer set with source, owner, confidence, exceptions.

**Stop:** Do not submit unreviewed security/compliance claims.
