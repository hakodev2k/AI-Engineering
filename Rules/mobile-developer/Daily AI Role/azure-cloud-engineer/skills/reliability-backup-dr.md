# Skill: Reliability, Backup, and DR

**Purpose:** align Azure design with RTO/RPO and failure modes.
**Steps:** identify critical user journeys → enumerate zonal/regional/dependency failures → define availability targets → design redundancy → configure backup retention → document restore ownership → define failover/failback criteria → test restore/failover → record measured RTO/RPO.
**Quality:** backup configuration alone is not evidence; successful restore/failover testing is required for critical workloads.
**Escalate:** when business requirements exceed service capabilities or budget authority.
