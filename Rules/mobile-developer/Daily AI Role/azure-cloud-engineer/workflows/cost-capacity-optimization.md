# Workflow: Cost and Capacity Optimization

**Trigger:** budget pressure, sustained low utilization, scale forecast, quota risk.
**Stages:** baseline spend/utilization → inventory top cost/capacity drivers → verify workload criticality → analyze quota/scale → model options → reliability/security review → choose reversible actions → approval if material production effect → implement → measure 7/30-day outcome or agreed window → document learning.
**DoD:** savings or capacity improvement demonstrated without violating service objectives.
