# Skill: Technical Content Production
**Trigger:** need for tutorial, guide, FAQ, article, reference walkthrough, or migration content.
**Inputs:** audience, goal, source contracts, working environment, sample code, deadline.
**Procedure:** define one developer outcome; verify facts; build minimal working path; draft around actions and evidence; add prerequisites, expected outputs, failure handling, limits, next steps; run every command; request independent review; correct at most two cycles before escalation.
**Outputs:** publishable content plus verification evidence.
**Constraints:** no unsupported claims, hidden setup, secrets, or roadmap promises.
**Quality:** task-oriented, reproducible, current, version-aware.
**Failure:** if sample cannot be reproduced, content is not publishable.
