# Skill: Dashboard Design
Trigger: teams need shared operational or service-health views.
Inputs: user journeys, SLOs, telemetry contracts, incident questions and audience.
Procedure: define audience and decisions; create overview from user-impact signals; add dependency and resource drill-down; expose deployment/version context; show missing-data state; keep units/time windows consistent; remove decorative panels; test common incident questions.
Output: dashboard specification and verification evidence.
Quality: each panel answers a question and leads to a next diagnostic step.
