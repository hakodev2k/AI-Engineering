# Documentation Quality Metrics

Prefer outcome metrics:
- task success or successful completion without support escalation
- documentation-caused incident/defect rate
- time-to-answer or time-to-complete key tasks
- search success / zero-result and reformulation rate
- support-ticket deflection only when causality is credible
- stale-content age and update latency after product change
- verified-example pass rate
- broken-link rate
- review defect escape rate
- percentage of high-risk docs with named owner and version scope

Avoid vanity use of page views alone; traffic can indicate importance but not correctness or usefulness.
