# Technical Lead Skills

Task-focused procedures for AI-assisted work in the Technical Lead discipline. These files are Markdown guidance, require no installation, and should be loaded selectively according to the task.

Each skill file is self-contained and may be copied independently; this README, sibling skills, and any separate rule collection are optional context rather than runtime dependencies.

## Usage

1. Choose the smallest skill that matches the requested technical leadership outcome.
2. Supply the decision scope, stakeholders, accountable owners, constraints, evidence, delivery context, risk tolerance, and acceptance criteria the skill requires.
3. If a separate rule collection is available, apply its relevant constraints as additional context.
4. Preserve accountable ownership and authorization boundaries; technical recommendations do not grant permission for production, security, personnel, budget, or external commitments.
5. Follow the skill's verification and stop conditions; record decisions, dissent, assumptions, owners, follow-up work, and residual risk.
