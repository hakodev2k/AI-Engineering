# Model Selection Rules
## Purpose
Ensure model choices are evidence-based, fit-for-purpose, and reversible.
## Scope
Foundation models, embedding models, rerankers, classifiers, and provider selection.
## MUST
- Define task requirements, quality targets, latency, cost, context, safety, and deployment constraints before selecting a model.
- Compare candidate models using representative evaluations and production-relevant constraints.
- Record material trade-offs and fallback options for high-impact decisions.
## MUST NOT
- Select a model solely because it is newer, larger, or popular.
- Claim superiority without benchmark or evaluation evidence.
## SHOULD
- Prefer simpler or cheaper models when they meet required quality and reliability targets.
## Exceptions
Exceptions require documented urgency, risk, evidence, and review.
## Verification
Review evaluation results, cost/latency data, decision records, and fallback readiness.
