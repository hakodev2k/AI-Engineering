# Bias and Fairness Rules
## Purpose
Detect and control harmful performance disparities.
## Scope
Models affecting people, access, ranking, pricing, risk, or consequential decisions.
## MUST
- Identify relevant protected or risk-sensitive cohorts before release when legally and ethically appropriate.
- Measure material performance disparities and document mitigation decisions.
- Escalate unacceptable disparate impact for human review.
## MUST NOT
- Infer that aggregate accuracy implies equitable behavior.
- Use sensitive attributes or proxies contrary to policy or law.
## SHOULD
- Evaluate intersectional cohorts where sample size supports meaningful conclusions.
## Exceptions
Unavailable sensitive data requires documented alternative risk assessment.
## Verification
Review cohort metrics, data governance, mitigation evidence, and approval records.
