# Incident Triage Workflow

## Trigger
Production alert or incident report.

## Stages
1. Collect context.
2. Build timeline.
3. Analyze evidence.
4. Delegate validation.
5. Produce report.
6. Verify recovery.

## Retry
Maximum 2 retries for transient data collection failures only.

## Approval
Stop before production remediation.

## Done
Evidence collected, findings validated, risks documented.
