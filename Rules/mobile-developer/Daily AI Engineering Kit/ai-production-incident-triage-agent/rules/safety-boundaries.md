# Safety Boundaries

## MUST
- Preserve evidence before proposing changes.
- Record facts separately from hypotheses.
- Require approval before production changes.
- Protect secrets and sensitive data.

## MUST NOT
- Delete production data.
- Run destructive commands.
- Change infrastructure without approval.
- Claim root cause without evidence.

## SHOULD
- Prefer reversible remediation.
- Include verification steps for every recommendation.
