# Change Verification Skill

## Purpose
Verify AI-assisted repository changes using evidence.

## Use When
- Reviewing pull requests
- Validating generated code
- Checking refactors or dependency changes

## Procedure
1. Identify changed files and intended behavior.
2. Locate related modules, tests, contracts, and configuration.
3. Separate facts, assumptions, and risks.
4. Validate implementation against requirements.
5. Execute available build and test checks.
6. Inspect unexpected side effects.
7. Produce findings with evidence.

## Output
Finding, evidence, confidence, risk, recommendation, verification status.

## Stop Conditions
Stop when required context is unavailable or approval is required.
