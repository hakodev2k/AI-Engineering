# Incident Safety Rules

## MUST
- Preserve evidence before changes.
- Record commands and outputs.
- Require approval for production changes.
- Verify recovery after mitigation.

## MUST NOT
- Delete production data.
- Disable security controls.
- Apply irreversible changes without approval.
- Claim root cause without evidence.

## SHOULD
- Prefer reversible mitigations.
- Keep changes minimal.
