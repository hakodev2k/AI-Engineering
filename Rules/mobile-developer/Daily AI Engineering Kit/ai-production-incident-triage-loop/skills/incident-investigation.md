# Incident Investigation Skill

Purpose: investigate incidents using evidence instead of guesses.

Steps:
1. Capture alert, timeline, affected services, and recent changes.
2. Inspect logs, metrics, traces, and deployment history.
3. Separate facts from hypotheses.
4. Create ranked hypotheses with evidence.
5. Validate one hypothesis at a time.
6. Propose smallest safe mitigation.
7. Verify recovery.

Stop conditions:
- Evidence is insufficient.
- Approval is required.
- Maximum investigation cycle is reached.

Output: incident finding with evidence, confidence, risk, and verification status.
