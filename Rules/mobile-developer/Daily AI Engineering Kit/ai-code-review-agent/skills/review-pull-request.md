# Review Pull Request Skill

## Purpose
Perform structured AI code review.

## Process
1. Identify changed files and affected modules.
2. Collect repository conventions and tests.
3. Separate facts from assumptions.
4. Review correctness, security, performance, and maintainability.
5. Produce findings with evidence.
6. Verify findings against code and tests.

## Output
Each finding contains:
- location
- evidence
- risk
- recommendation
- confidence

## Stop Conditions
Stop when context is insufficient or destructive action is requested.
