# Investigate Incident Skill

## Purpose
Perform structured production debugging.

## Steps
1. Identify affected service and symptoms.
2. Collect logs, metrics, traces, deployments, and configuration changes.
3. Separate facts from hypotheses.
4. Locate code paths and dependencies.
5. Validate each hypothesis with evidence.
6. Propose smallest safe remediation.
7. Record verification steps.

## Output
Finding, evidence, confidence, affected component, risk, verification status.

## Stop Conditions
Stop when evidence is insufficient or approval is required.
