# Incident Safety Rules

## MUST
- Require evidence before claiming root cause.
- Preserve logs and timestamps.
- Record confidence levels.
- Request approval before production changes.

## MUST NOT
- Delete production data.
- Run destructive commands.
- Disable security controls.
- Present assumptions as facts.

## SHOULD
- Prefer reversible actions.
- Minimize investigation scope.
- Document unresolved risks.
