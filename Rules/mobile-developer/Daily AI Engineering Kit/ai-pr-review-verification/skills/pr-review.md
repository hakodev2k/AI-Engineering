# PR Review Skill

## Purpose
Perform structured AI code review with evidence.

## Process
1. Collect changed files and related tests.
2. Identify affected components.
3. Check correctness, security, performance, and maintainability.
4. Separate facts from hypotheses.
5. Produce findings with evidence.
6. Validate high-risk findings.

## Output
Each finding must include:
- location
- evidence
- severity
- risk
- recommendation
- verification status

## Stop Conditions
Stop when context is insufficient or requested access exceeds permissions.
