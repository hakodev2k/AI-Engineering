# PR Review Workflow

## Trigger
Pull request opened or updated.

## Stages
1. Collect PR diff.
2. Gather repository context.
3. Run specialized reviews.
4. Consolidate findings.
5. Verify evidence.
6. Publish review report.

## Retry policy
Maximum 2 retries for transient tool failures.
Preserve collected evidence.
Escalate after repeated failure.

## Definition of Done
- Review completed.
- Findings validated.
- Uncertainty documented.
