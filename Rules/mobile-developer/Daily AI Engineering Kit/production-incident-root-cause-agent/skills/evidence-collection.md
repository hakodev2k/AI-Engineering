# Evidence Collection Skill

## Purpose
Collect incident facts before forming conclusions.

## Process
1. Identify incident timeline.
2. Collect alerts, logs, traces, metrics, deployments and affected components.
3. Separate facts from assumptions.
4. Record evidence sources.
5. Produce an investigation package.

## Output
Finding records with evidence, timestamp, source and confidence.

## Failure Handling
Stop when required evidence is unavailable and record missing inputs.
