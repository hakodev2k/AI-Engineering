# Root Cause Workflow

## Trigger
Production incident detected.

## Stages
1. Collect context.
2. Build timeline.
3. Analyze evidence.
4. Review hypotheses.
5. Recommend remediation.
6. Verify outcome.

## Retry Policy
Maximum 3 retries for transient tool failures only.

## Approval Points
Production changes require explicit human approval.

## Done
Evidence-backed cause, remediation plan, and verification result exist.
