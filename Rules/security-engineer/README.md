# Security Engineer Rules

Operating constraints for AI-assisted work performed in the Security Engineer discipline. These files are policy guidance, require no installation, and should be combined with repository-specific instructions and deterministic checks.

## Usage

1. Select the smallest set of rules that covers the planned change.
2. Resolve conflicts using repository policy, explicit approval boundaries, and the stricter safety requirement.
3. Pair the rules with relevant procedures from the [available engineering skills](../../Skills/).
4. Convert critical requirements into tests, hooks, or CI checks in the target repository.
