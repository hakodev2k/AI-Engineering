# Namecheap MCP/API Connector

Reusable MCP stdio connector for Namecheap domain inventory and controlled DNS operations.

## Transport and official research

No official Namecheap MCP server was identified in Namecheap's official API documentation during this run, so the connector uses Namecheap's official XML API directly. Official sources researched on 2026-09-15: API introduction and authentication (`https://www.namecheap.com/support/api/intro/`), API method catalogue (`https://www.namecheap.com/support/api/methods/`), domain methods, DNS methods, `domains.getList`, `domains.getInfo`, `domains.dns.getList`, `domains.dns.getHosts`, `domains.dns.setDefault`, and `domains.dns.setHosts`.

Production endpoint: `https://api.namecheap.com/xml.response`. Sandbox endpoint: `https://api.sandbox.namecheap.com/xml.response`. Sandbox is the connector default.

## Authentication

Namecheap requires `ApiUser`, `ApiKey`, `UserName`, and a whitelisted IPv4 `ClientIp` on API requests. Configure `NAMECHEAP_API_USER`, `NAMECHEAP_API_KEY`, `NAMECHEAP_USERNAME`, and `NAMECHEAP_CLIENT_IP`. Namecheap requires at least one IPv4 address to be whitelisted in API Access before calls work. Credentials remain inside the connector transport and are never tool arguments or results.

Namecheap API keys are broad account credentials rather than granular OAuth scopes. Least privilege therefore relies on account/API configuration plus this connector's fixed tool allowlist. Do not expose the API key to the model, logs, source control, or examples.

## Tools and risk

READ: `namecheap.domain.list`, `namecheap.domain.get`, `namecheap.domain.check`, `namecheap.domain.lock.get`, `namecheap.dns.nameserver.list`, `namecheap.dns.host.list`.

HIGH_RISK: `namecheap.dns.nameserver.set_default`, `namecheap.dns.nameserver.set_custom`, `namecheap.dns.host.replace_all`.

DNS and nameserver changes are HIGH_RISK because they can redirect or interrupt production traffic. `setHosts` is especially sensitive: Namecheap explicitly documents that host records omitted from the request are deleted. This connector therefore models it as `replace_all`, not an innocuous “add record” operation. Domain registration, renewal, transfers, contact mutation, registrar-lock mutation, account/balance operations, SSL purchase/revocation, email forwarding, and domain deletion are intentionally not exposed.

## Approval model

HIGH_RISK tools are disabled unless `NAMECHEAP_ENABLE_HIGH_RISK=true`. They also require a 64-character `approval_token` generated by HMAC-SHA256 over the exact tool name and canonical exact payload using `NAMECHEAP_APPROVAL_SECRET`. Changing the domain, nameservers, record address, TTL, or any other field invalidates approval. Keep the approval secret in a trusted operator/approval service, outside model context.

## Installation and running

Requires Node.js 20+.

```bash
npm install
npm run build
npm test
npm start
```

The server uses MCP stdio and can be launched by MCP clients that support local stdio servers.

## Reliability

Every provider request has an AbortController timeout. READ calls use bounded retries for HTTP 429, server errors, and transient network failures. HIGH_RISK mutations explicitly disable automatic retries to avoid repeating an ambiguous DNS change. Authentication, provider validation, and XML API errors fail closed.

Namecheap's public API documentation does not publish one universal numeric request quota suitable for every command, so the connector does not invent one. It reacts to HTTP throttling and avoids hidden fan-out. Domain listing exposes Namecheap's documented page size of 10-100.

## Validation and security

The upstream host is selected internally from the two official Namecheap environments; tool calls cannot choose arbitrary URLs, preventing an agent-controlled SSRF/credential-forwarding primitive. Domains, SLDs, record names, record types, record counts, TTLs and MX priorities are bounded. DNS replacement is capped at 100 records per tool call even though Namecheap DNS can support more, reducing blast radius. Provider-returned XML content is wrapped as `untrusted_provider_data`; domain metadata and DNS values are data, not instructions.

The connector exposes no raw API command tool. Retrieved content cannot enable HIGH_RISK mode, change credentials, change the client IP, or mint approvals.

## DNS behavior

`namecheap.dns.host.list` requires the domain to use suitable Namecheap DNS. `namecheap.dns.nameserver.set_default` switches to Namecheap default DNS. `namecheap.dns.nameserver.set_custom` replaces authoritative nameservers and can disable Namecheap value-added DNS services. `namecheap.dns.host.replace_all` sends the complete desired host set; omitted existing records are removed by Namecheap.

## Errors

Namecheap returns XML with `ApiResponse Status="ERROR"` and provider error numbers/messages. The connector parses this and surfaces a bounded error without exposing the API key. HTTP authentication/availability failures and timeouts are also surfaced. Mutations are single-attempt.

## Tests

`npm test` requires no live credentials. Tests cover required credential configuration, IPv4 validation, default denial of HIGH_RISK operations, exact-payload approval, credential placement inside transport, and no blind mutation retry.

## Limitations

This is a curated nine-tool connector, not a complete Namecheap API wrapper. Namecheap has no official MCP transport identified here, no OAuth scope model for these legacy API commands, and requires source IPv4 whitelisting. The connector does not implement inbound events/webhooks, domain purchases/renewals/transfers, billing, account administration, SSL lifecycle, contact PII reads, email forwarding, Dynamic DNS, or nameserver child-host operations. Always validate DNS changes in Namecheap sandbox before production.
