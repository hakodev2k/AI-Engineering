# Workflow examples

## Find an open slot

Tool: `calendly.availability.list_times`

```json
{
  "event_type": "https://api.calendly.com/event_types/AAAAAAAAAAAAAAAA",
  "start_time": "2026-08-26T00:00:00+07:00",
  "end_time": "2026-08-27T00:00:00+07:00"
}
```

Permission: READ. Approval: no.

Expected output shape: `{ "ok": true, "tool": "calendly.availability.list_times", "risk": "READ", "data": ... }`.

## Book an invitee

Tool: `calendly.booking.create`

```json
{
  "event_type": "https://api.calendly.com/event_types/AAAAAAAAAAAAAAAA",
  "start_time": "2026-08-26T14:00:00+07:00",
  "invitee": {
    "name": "Example User",
    "email": "user@example.com",
    "timezone": "Asia/Ho_Chi_Minh"
  },
  "approval_id": "<HMAC generated by trusted approval service>"
}
```

Permission: WRITE. Approval: required by default. Expected data is the Calendly MCP/API booking response.

## Cancel a meeting

Tool: `calendly.event.cancel`

```json
{
  "uuid": "AAAAAAAAAAAAAAAA",
  "reason": "Customer requested a different time",
  "approval_id": "<HMAC generated by trusted approval service>"
}
```

Permission: DESTRUCTIVE. Approval: required. The connector never retries this action automatically.
