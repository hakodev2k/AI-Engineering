# Roadmap

AI Engineering evolves as a reusable pick-and-copy library. This roadmap describes direction, not a release schedule or commitment to ship every item.

## Current priorities

- Make useful content discoverable without requiring a developer to browse every collection.
- Preserve standalone copy boundaries for individual Rules and Skills and complete Role, kit, guard, and connector directories.
- Improve semantic review: distinct scope, clear selection guidance, current claims, safe examples, and evidence-based verification.
- Keep repository-wide automation focused on source quality rather than treating the collections as one application.

## Near-term direction

- Expand starter-pack coverage only for recurring, clearly bounded use cases.
- Improve catalogue summaries and selection notes where package names alone do not explain the difference.
- Strengthen provenance and review-date guidance for time-sensitive provider, framework, protocol, and security claims.
- Improve contributor workflows for proposing new content, comparing overlap, and documenting standalone dependencies.
- Keep MCP discovery aligned with the actual provider directories while preserving connector-local installation and validation.

## Ongoing maintenance

- Repair broken navigation, invalid examples, incomplete schemas, undocumented scripts, and missing package-local prerequisites.
- Review high-risk guidance for least privilege, human approval, safe failure, rollback, and evidence handling.
- Retire or deprecate content when it becomes misleading, unsupported, or superseded; provide replacement guidance when applicable.
- Keep onboarding, composition, FAQ, trust, and quality documentation synchronized with the repository model.

## Explicit non-goals

- Turning the repository into one application, framework, or mandatory runtime.
- Requiring developers to install, build, test, or load every collection.
- Forcing similar Skills to be merged solely because their subject areas overlap; independently useful procedures may coexist.
- Publishing releases or tags on a fixed cadence. Adopters can record a commit SHA as their source revision.
- Claiming universal production readiness, compliance, or security certification.
- Granting agents authority through documentation or connector availability.

## Propose a roadmap item

Open a focused issue using the appropriate template. Describe the adopter problem, similar existing content, smallest useful copy unit, safety implications, validation plan, and measurable improvement to discovery or reuse.
