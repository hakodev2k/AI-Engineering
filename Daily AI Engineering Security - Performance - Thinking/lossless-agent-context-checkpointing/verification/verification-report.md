## Static package checks

### Topic gate
**PASS** — problem is specifically about token/context management and long-running agent compaction.

### Current evidence
**PASS** — `evidence/research.md` cites multiple recent 2026 public reports from OpenAI Codex and Anthropic Claude Code plus official OpenAI compaction guidance. Evidence, interpretation, and proposed solution are separated.

### Existing-solution analysis
**PASS** — package documents automatic/manual compaction, free-form summaries, transcript replay, prompt cache, and transcript-resident tool output, plus their evidence-backed limitations.

### Concrete improvement
**PASS** — package introduces a provider-independent operational checkpoint, per-model context budget, recovery reserve, artifact externalization, deterministic verification, bounded recovery, and resume validation.

### Skills
**PASS** — skills include triggers, inputs, procedures, decisions, constraints, outputs, metrics, verification, failure handling, and stop conditions.

### Rules
**PASS after correction** — MUST/MUST NOT/SHOULD rules are observable/testable. One Markdown emphasis typo was detected during final review and corrected before this report.

### Subagent delegation
**PASS** — Budget Analyst, Checkpoint Curator, Checkpoint Verifier, and Recovery Agent have distinct responsibilities. The curator is not the sole verifier.

### Workflow bounds
**PASS** — checkpoint correction, compaction retry, recovery attempt, and older-checkpoint fallback are explicitly bounded. No unlimited retry loop exists.

### Hooks/scripts
**PASS static inspection** — scripts are native `.py` files, not pseudocode embedded in Markdown. They validate inputs, use standard-library-only implementations, avoid destructive operations, use atomic checkpoint write, generate SHA-256 metadata, and return meaningful non-zero failure codes.

### Token correctness guard
**PASS** — policy does not optimize tokens by silently deleting required context. Durable artifacts must be externalized/verifiable before intentional eviction.

### Mixed-model safety
**PASS** — budget rules require the effective context limit for each active model/subagent rather than inheriting the coordinator’s limit.

### Compaction timing
**PASS** — policy defines soft/checkpoint/hard-stop thresholds plus a recovery reserve and explicitly forbids waiting for 100% context utilization.

### Verification semantics
**PASS** — implementation, measurement, and verification are separated. `verified` checkpoint state requires explicit successful command/test evidence in the deterministic verifier.

### Hidden reasoning
**PASS** — package explicitly forbids storing hidden chain-of-thought and uses observable facts, assumptions, decisions, evidence, blockers, and next actions instead.

### Secrets
**PASS by design/static review** — rules and artifact policy prohibit secret persistence. No credential, token, API key, or repository secret is included in generated files.

### README consistency
**PASS** — README references the files generated by this package and describes their actual responsibilities.
