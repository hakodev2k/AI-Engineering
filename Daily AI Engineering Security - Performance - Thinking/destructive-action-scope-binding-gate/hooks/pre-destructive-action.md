# Hook: Pre-Destructive Action

## Trigger
Immediately before a destructive tool/command executes.

## Preconditions
Policy, approval envelope, and exact planned-action JSON exist.

## Action
Run deterministic scope validation.

## Script / command
`python scripts/scope_gate.py <policy.json> <approval-envelope.json> <planned-action.json>`

## Expected result
Exit 0 with `PASS`.

## Failure behavior
Exit 2 blocks mutation and requires a new approval envelope if state/scope legitimately changed. Exit 1 blocks because validation itself failed.

## Blocks completion
Yes. Mandatory human approval cannot be bypassed by configuration generated by the agent.
