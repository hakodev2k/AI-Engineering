# AI Engineer Skills

Task-focused procedures for AI-assisted work in the AI Engineer discipline. These files are Markdown guidance, require no installation, and should be loaded selectively according to the task.

## Usage

1. Choose the skill that matches the requested outcome.
2. Supply the inputs, repository context, versions, constraints, and acceptance criteria it requires.
3. Apply the matching [AI Engineer rules](../../Rules/ai-engineer/).
4. Follow the skill's verification and stop conditions; do not infer permission for sensitive actions.
