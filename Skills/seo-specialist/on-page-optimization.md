# On-Page Optimization

## Purpose
Improve a page's relevance, clarity, crawl signals, usability, and conversion alignment without degrading content quality.

## When to use
Use for underperforming pages, new content, changed intent, or post-audit remediation.

## Inputs
Page, target intent, query data, SERPs, analytics, internal links, and conversion goals.

## Context to inspect
Title, headings, body, media, entities, metadata, URL, canonicals, internal links, rendered content, and competing pages.

## Core knowledge
On-page SEO is intent satisfaction plus clear machine-readable signals. Keyword repetition is not a substitute for useful coverage.

## Procedure
1. Confirm page purpose and target intent.
2. Compare content with current SERP expectations.
3. Improve title and primary heading for clarity.
4. Fill meaningful information gaps.
5. Strengthen evidence, examples, and expert value.
6. Improve internal anchors and related navigation.
7. Review metadata, media semantics, and structured data eligibility.
8. Preserve conversion and accessibility quality.
9. Publish and measure.

## Decision points
Refresh when the URL remains authoritative; consolidate when overlap causes cannibalization; create a new page only for distinct intent.

## Common failure patterns
Keyword stuffing, title churn, hidden content, copied competitor structure, and changing high-performing pages without a hypothesis.

## Verification
Check rendered HTML, indexability, metadata, links, analytics annotations, and post-release search/conversion trends.

## Expected output
A documented set of evidence-backed page improvements and validation results.

## Stop conditions
Stop if changes conflict with legal, brand, accessibility, or product requirements.
