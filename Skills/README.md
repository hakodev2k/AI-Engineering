# Engineering Skills

Focused, reusable procedures for common engineering tasks. Each skill explains its purpose, required context, bounded procedure, verification, expected output, failure handling, and escalation conditions.

These Markdown skills are tool-neutral guidance, not standalone executables or installable Codex `SKILL.md` packages. No installation is required.

## How to use

1. Select a discipline and the smallest skill that matches the task.
2. Read its inputs, preconditions, constraints, and stop conditions before acting.
3. Combine it with the matching [Rules](../Rules/) discipline.
4. Supply repository-specific commands, paths, versions, and acceptance criteria.
5. Preserve verification evidence and report residual uncertainty explicitly.

Do not concatenate every skill into one prompt. Loading unrelated procedures increases context size and can introduce conflicting assumptions.
