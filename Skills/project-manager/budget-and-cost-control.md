# Budget and Cost Control

## Purpose
Plan and control project spending while connecting financial variance to scope, schedule, risk, and expected value.

## When to use
Use for projects with approved budgets, vendor spend, capital constraints, or material staffing and infrastructure costs.

## Inputs
Budget baseline, rates, contracts, purchase commitments, forecasts, actual costs, scope changes, contingency, and financial policies.

## Context to inspect
Inspect accounting periods, capitalization rules, procurement commitments, currency/tax effects, usage-based costs, and approval thresholds.

## Core knowledge
Cost control requires committed cost and forecast-at-completion, not only invoices already posted. Budget variance must be explained causally and connected to remaining work.

## Procedure
1. Build a cost baseline aligned to work and milestones.
2. Separate fixed, variable, committed, actual, forecast, and contingency amounts.
3. Define cost owners and approval thresholds.
4. Reconcile actuals regularly with source systems.
5. Forecast remaining cost using current schedule and staffing assumptions.
6. Analyze variance by cause, not merely category.
7. Quantify cost impact of scope and schedule changes before approval.
8. Track contingency drawdown and residual risk.
9. Surface forecast-at-completion changes early.
10. Close financial commitments and unused reserves at completion.

## Decision points
Use detailed earned-value techniques only where governance and data quality justify them. Otherwise use simpler forecasts tied to real delivery evidence.

## Common failure patterns
Ignoring committed spend, hiding overruns in contingency, late invoice surprises, and separating cost decisions from scope outcomes.

## Verification
Actuals reconcile, completion forecast is current, variances have explanations, and approved changes appear in financial and delivery baselines.

## Expected output
A current cost baseline, variance analysis, and completion forecast with decision-ready financial risks.

## Stop conditions
Escalate when forecast exceeds delegated tolerance, financial data is unreliable, or spending lacks authorization.
