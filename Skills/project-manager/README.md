# Project Manager Skills

Standalone, tool-neutral procedures for AI-assisted project management. Each skill can be copied independently; this index and sibling skills are optional navigation rather than runtime dependencies.

## How to use

1. Select the smallest skill matching the current delivery problem.
2. Provide the project context, owners, constraints, evidence, acceptance criteria, and decision boundaries it requires.
3. Follow its verification and escalation conditions without inferring authority over budget, scope, people, vendors, or releases.
