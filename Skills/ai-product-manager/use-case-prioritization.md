# AI Use-Case Prioritization

## Purpose
Rank AI use cases using customer value, technical feasibility, risk, data readiness, economics, and strategic leverage.

## When to use
Use when choosing among multiple AI opportunities, allocating roadmap capacity, or deciding which experiments deserve investment.

## Inputs
Candidate use cases, customer evidence, expected value, model evaluations, data readiness, engineering estimates, risk assessments, cost assumptions.

## Context to inspect
Roadmap dependencies, model limits, compliance requirements, workflow criticality, human-review options, serving costs, and current alternatives.

## Core knowledge
AI feasibility is multidimensional. A high-value use case can still be poor if evaluation is impossible, required data cannot be used, or error consequences exceed user tolerance.

## Procedure
1. Define each use case in terms of user outcome.
2. Score customer value and frequency.
3. Estimate model capability requirements and current evidence.
4. Assess data availability and rights.
5. Estimate implementation and operational complexity.
6. Assess safety, privacy, security, and regulatory risk.
7. Estimate unit economics and scalability.
8. Identify strategic learning or platform reuse.
9. Rank candidates and document uncertainty.
10. Select a portfolio balancing near-term value and learning.

## Decision points
Favor use cases with strong value and verifiable outputs. Use experiments for uncertain but strategically important bets rather than committing full roadmap scope.

## Common failure patterns
Single-score prioritization, ignoring verification cost, underestimating human review, and ranking by executive enthusiasm rather than evidence.

## Verification
Re-score with engineering, design, data, and risk stakeholders; ensure major assumptions are visible and sensitivity-tested.

## Expected output
A prioritized use-case portfolio with rationale, assumptions, risk, and experiment recommendations.

## Stop conditions
Stop when critical feasibility or risk information is unavailable and would materially change ranking.
