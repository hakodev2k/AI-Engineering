# Accessibility Engineer Skills

Task-focused procedures for accessibility assessment and remediation. Each Markdown file is self-contained and can be copied independently.

## Usage

Provide the affected journey, supported platforms, accessibility target, known constraints, and acceptance criteria. Pair with the accessibility rules and target-repository standards; do not use an automated scan as the only review method.
